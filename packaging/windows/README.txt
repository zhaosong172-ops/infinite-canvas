Infinite Canvas Windows 便携版
==============================

这是一个免安装的 Windows x64 版本，内置 Node.js 运行时，解压后即可使用。

启动
----
1. 解压整个目录（不要只复制 exe），保持目录结构完整。
2. 双击 InfiniteCanvas.exe。
3. 启动器会拉起后端（8080）和前端（3000），就绪后自动打开浏览器。
   若浏览器没有自动打开，手动访问 http://127.0.0.1:3000 。
4. 关闭黑色命令行窗口即退出全部服务。

默认账号
--------
用户名：admin
密码：infinite-canvas
请打开同目录的 .env 修改 ADMIN_PASSWORD 和 JWT_SECRET 后再对外使用。

数据与配置
----------
- 数据库、日志和提示词缓存都在 data 目录（默认 SQLite）。
- .env 与官方 Docker 版一致，可改用 MySQL / PostgreSQL。
- ComfyUI 服务端在「系统设置 → 私有配置 → ComfyUI 服务地址」里配置；
  模型渠道里新建 ComfyUI 渠道时不选 Bridge，即可由后端直连该地址执行工作流。
- 端口占用时，可在 .env 里改 PORT（后端），前端固定 3000。

常见问题
--------
- 首次运行 Windows 可能提示“已保护你的电脑”，选择“更多信息 → 仍要运行”即可（未签名）。
- 提示端口被占用：关掉占用 8080/3000 的程序，或修改 .env 中的 PORT。
- 想彻底卸载：关闭服务后删除整个目录即可，不会写入注册表。
